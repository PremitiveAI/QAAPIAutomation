## Download Nodejs
https://nodejs.org/dist/v24.12.0/node-v24.12.0-x64.msi

## After Installation Check the version in terminal
```bash
node -v
```

## Project clone from url

```bash
git clone<url>
```

## Inside the Project Run Below command
## TO install the package use this command

```bash
npm -i
```

## Update the env.local with keys
NEXT_PUBLIC_API_URL=
API_TOKEN=
NEXT_PUBLIC_OLA_MAPS_API_KEY=
OLA_MAPS_API_KEY=
 
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=
GOOGLE_MAPS_API_KEY=

## Start the Application Locally
First, run the development server:

```bash
npm run dev
```
